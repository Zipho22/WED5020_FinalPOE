## CHANGELOG

All notable changes made to the Gauteng Higher Learning Institution (GHLI) website project are recorded in this file.

# Version 1.0 – Project Setup

* Created the GHLI website project.
* Created the five main HTML pages: Home, About, Courses, Enquiries and Contact.
* Set up the project folders for CSS, JavaScript and images.

# Version 1.1 – Website Content and Images

* Added institutional information and website content.
* Added the GHLI logo and relevant images.
* Added descriptions and alternative text to images.
* Added navigation links between website pages.

# Version 1.2 – CSS Styling

* Created an external CSS stylesheet.
* Applied the navy blue, gold and white colour scheme.
* Added typography and consistent styling.
* Styled headings, paragraphs, images and navigation links.
* Added hover effects to navigation links.

# Version 1.3 – Responsive Design

* Added responsive design features.
* Added media queries for different screen sizes.
* Adjusted images and typography for smaller devices.
* Tested the website using Google Chrome Developer Tools.

# Version 1.4 – Enquiry and Contact Forms

* Added a student enquiry form using Google Forms.
* Added a separate contact form using Google Forms.
* Added a Google Maps embed to the Contact page.
* Tested the forms to confirm that responses could be submitted.

# Version 1.5 – Search Engine Optimisation (SEO)

* Added descriptive page titles.
* Added meta descriptions and relevant keywords.
* Improved HTML heading structure.
* Reviewed image alternative text.
* Added robots.txt.
* Created sitemap.xml with the website page URLs.

# Version 1.6 – Testing and Publishing

* Tested website navigation and page links.
* Checked image display and website layout.
* Tested the embedded forms and Google Maps.
* Published the website using GitHub Pages.
* Updated the sitemap and robots.txt files with the live website address.
